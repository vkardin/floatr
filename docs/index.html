Install in three steps

Store listings are coming soon. Until then, install the release archive.

Download

Get aloft-chrome or aloft-firefox zip from GitHub Releases.

Load

Chrome, Edge, Brave, Opera: unzip, open chrome://extensions, turn on Developer mode and click Load unpacked. Firefox: about:debugging → Load Temporary Add-on.

Float

Hover any video and click the Aloft button, or press Alt+Shift+P.

FAQ

Does Aloft send my data anywhere?

No. Everything stays in your browser storage. There are no servers, analytics or trackers.

Why do subtitles show in Aloft's window but not in native PiP?

Native Picture-in-Picture shows only the video frame. Aloft's Document Picture-in-Picture window can show HTML, so subtitles drawn by the site are copied there.

Does it work in Firefox?

Yes. Firefox has no Document Picture-in-Picture API, so Aloft opens a draggable, resizable mini player on top of the page with the same controls.

Where are my bookmarks stored?

In browser sync storage, so they follow you to other computers signed in to the same browser profile. Export them to Markdown at any time.

The floating window does not open from the popup.

Some browsers require a click on the page itself. Click the video once, then use the button over the video or Alt+Shift+P.
